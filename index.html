☁️ Sync across devices

            
Sync your data via a private GitHub Gist. Only you (with your token) can access it.

            

              
    
                
  1. Create a GitHub Personal Access Token with the gist scope only (github.com/settings/tokens/new).
    2. 
                
  2. Paste the token below and tap Push now. That first push creates a new private Gist and fills in the Gist ID.
    3. 
                
  3. On your other device, install the app, paste the same token and the Gist ID, and tap Pull.
    4.

⌚ Google Health / Fitbit (activity import)

            
Pull today's steps, calories, and workouts from your Fitbit data via the Google Health API — and optionally auto-complete a habit when you've been active. Read-only; runs through your own Worker so no secrets live in the app.

            

              One-time setup (Google Cloud + Worker)
              
    
                
  1. In Google Cloud Console, create a project and enable the Google Health API.
    2. 
                
  2. Configure the OAuth consent screen (External), add yourself as a Test user, and add the scope .../auth/googlehealth.activity_and_fitness.readonly.
    3. 
                
  3. Create an OAuth client ID of type Web application. Add this app's URL as an Authorized redirect URI: —
    4. 
                
  4. In your Worker folder run: wrangler secret put GOOGLE_CLIENT_ID and wrangler secret put GOOGLE_CLIENT_SECRET, then wrangler deploy.
    5. 
                
  5. Make sure your Worker URL is set above under Background reminders, then tap Connect.
    6.

🔔 Reminders

            
Get a notification at each habit's reminder time. Works best when the app is installed to your home screen and open in the background.

Reminders fire while the app is open or recently used; iOS may not deliver them when it's fully closed.
