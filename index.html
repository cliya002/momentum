☁️ Sync across devices

Sync your data via a private GitHub Gist. Only you (with your token) can access it.

  1. Create a GitHub Personal Access Token with the gist scope only (github.com/settings/tokens/new).
  2. Paste the token below and tap Push now. That first push creates a new private Gist and fills in the Gist ID.
  3. On your other device, install the app, paste the same token and the Gist ID, and tap Pull.

Pairing link carries your token — only send it to your own device (AirDrop, Notes). It never goes through any server.
